# Known pitfalls (read before coding)

The live rule set for this repository: every trap this build has hit, the rule
that now prevents it, and the test that guards it. It is short on purpose and it
is meant to be read in full at the start of every session, before the first line
of code.

- `AGENTS.md` section 0 step 1 requires this file; `docs/REVIEW_LOG.md` holds only
  history and points here.
- A fix that adds a rule adds its row **in the same commit**, with the guard test
  that proves it. A row that cannot be tested says `n/a (<reason>)` and why.
- `tests/test_invariants.py` enforces three things about the table: every cited
  `test_*` name exists, no ID is used twice, and the table is not duplicated back
  into the log.
- A rule whose feature was deliberately removed moves to "Retired pitfalls" at the
  bottom, naming the decision that removed it. The lesson that survives keeps its
  own row.

## Retired pitfalls

These rows guarded a feature that was deliberately removed. The lesson is kept so
it is not rediscovered as new; the code and its guard went with the feature.

- **PIT-02** (pacing) - passive tools were paced at the active rate because
  `tool_rate_args` ignored the mode. Speed control was removed on 2026-11-17
  (`docs/MASTER_PLAN.md` D3), so `tool_rate_args` and `tests/test_pacing.py` no
  longer exist. The surviving rule is `AGENTS.md` section 3.3: no pacer, rate
  limiter, delay or speed flag.
- **PIT-31** (nuclei template refresh) - `_refresh_templates` passed
  `env={"HOME"}`, and `Popen`/`execvpe` resolves a bare program name with the
  `PATH` inside that env, falling back to `os.defpath`. The function belonged to
  `reconkit install`/`update`, both removed on 2026-11-17 (D4). The lesson that
  survives is PIT-65: a custom `env=` must carry `PATH`, and an absolute path
  beats a bare name.
